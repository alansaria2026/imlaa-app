# إملائي 📝

تطبيق جوال تعليمي بلغة Flutter لمسابقات وتمارين الإملاء العربي، بتصميم هادئ وعصري يدعم الكتابة من اليمين إلى اليسار.

## التصميم

مستوحى من أفضل تطبيقات التعلّم على الجوال (مثل Duolingo) مع ألوان هادئة:

- **مسار التعلّم:** محطات دائرية متعرّجة لكل صفحة من الدرس؛ المنجزة ذهبية ✔، والحالية تنبض بزر «ابدأ»، والمقفلة رمادية.
- **أزرار ثلاثية الأبعاد** تنضغط عند اللمس، مع اهتزاز خفيف.
- **التميمة «البومة»** مرسومة بالشيفرة بثلاث حالات (سعيدة، تفكّر، حزينة).
- **التحفيز:** أيام متتالية 🔥، نقاط ⭐، وشارات في تبويب «إنجازاتي»، واحتفال بقصاصات ملونة عند إتمام الدرس.
- **تبويبات سفلية:** التعلّم، إنجازاتي، الإعدادات.
- **إمكانية الوصول:** الحركات المتكررة تتوقف عند تفعيل «تقليل الحركة» في الجهاز.

## الدرس الأول: اللام القمرية واللام الشمسية

يتكوّن الدرس من ٦ صفحات تمارين وفق التصميم الورقي (الصفحة ٤ في التصميم هي تعليمات تطبيق ص٣):

| الصفحة | النوع | المحتوى |
|---|---|---|
| ١ | مثال القاعدة | مخطط اللام القمرية (تُكتب وتُنطق) والشمسية (تُكتب ولا تُنطق)، أمثلة مسموعة، وجدول الحروف |
| ٢ | مثال | معادلات إضافة (الـ) وحذفها: اللحم − الـ = لحم، صلاة + الـ = الصلاة… |
| ٣ | تطبيق | كلمة + الـ = ؟ — أربع مجموعات من ٣ أسئلة من بنك الكلمات. **لا يُسمح بأي خطأ**: أي خطأ يعيد جميع الكلمات بترتيب مختلف، و«مؤشر النتيجة» يبدأ ١٠٠٪ وينقص ١٠٪ مع كل خطأ، والنقاط حسب المؤشر عند الإنهاء |
| ٤ | تطبيق | اكتب اسم الصورة مع (الـ) في مربعات بعدد الحروف؛ مربعا (الـ) بالأحمر، وتظهر الكلمة متصلة عند الإجابة الصحيحة، والسؤال الخاطئ يُعاد حتى تُحل الثمانية |
| ٥ | تحدي | اسمع الجملة واستخرج كلمة بلام قمرية وأخرى بلام شمسية — عشر جمل بترتيب مختلف كل مرة |
| ٦ | تطبيق | كلمة − الـ = ؟ (اللسان، البرج، الحرير…) — ثلاث مجموعات من ٣ أسئلة، بنفس قاعدة «لا يُسمح بأي خطأ» والمؤشر العكسي في ص٣ |

في كل صفحة: **رجوع**، **عنوان الدرس**، **الصفحة الرئيسية**، **مؤشر النتيجة**، **النقاط المكتسبة**، **القاعدة** (نافذة يمكن فتحها في أي وقت)، **تلميح**، **استمع** (نطق آلي بالعربية)، **التالي** (لا يُفعَّل في صفحات التمارين إلا بعد الإجابة عن جميع الفقرات).

## التشغيل

```bash
flutter pub get
flutter run
```

- النطق يعتمد على محرك تحويل النص إلى كلام في الجهاز (`flutter_tts`)؛ يُفضّل تثبيت الصوت العربي في إعدادات الجهاز.
- التقدم والنقاط محفوظان محليًا (`shared_preferences`).
- الخطوط (Tajawal و Noto Naskh Arabic) مضمّنة في `assets/fonts` فيعمل التطبيق دون اتصال. الخطوط مرخّصة برخصة SIL Open Font License.

## الاختبارات

```bash
flutter analyze
flutter test
```

تتحقق الاختبارات من صحة المحتوى (مثل أن كل جملة تحدٍّ فيها كلمة قمرية وأخرى شمسية) ومن مسار كل تمرين بالكامل على شاشة بعرض جوال.

## البنية

```
lib/
  data/lam_lesson.dart        محتوى الدرس (الكلمات، الصور، الجمل)
  lesson/lesson_screen.dart   هيكل الدرس وشريط الأدوات
  lesson/pages/               صفحات الدرس
  screens/                    الرئيسية: مسار التعلّم، الإنجازات، الإعدادات
  widgets/                    مكوّنات مشتركة (الأزرار ثلاثية الأبعاد، التميمة، «الـ» الحمراء، المربعات، لوحة المفاتيح)
  utils/arabic.dart           أدوات اللغة: نوع اللام، إزالة التشكيل، الأرقام العربية
```

لإضافة درس جديد: أضف محتواه في `lib/data/` وقائمة صفحاته على غرار `lib/lesson/lam_lesson_pages.dart`، ثم فعّل بطاقته في الصفحة الرئيسية.
